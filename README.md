# 📊 Competitor Sales Analysis Dashboard

## 📌 Project Overview
The **Competitor Sales Analysis Dashboard** provides insights into revenue performance, growth trends, market share, and country-level manufacturer comparisons.  
It helps businesses analyze competitor performance across categories, regions, and time periods.

## 🚀 Key Features

- 📈 Revenue & % Growth Analysis
- 🌍 Country-wise Manufacturer Revenue Comparison
- 🏙️ Urban vs Rural Sales Breakdown
- 🧩 Category-wise Performance (Mix, Extreme, Productivity, Select, Convenience)
- 📅 Date Range Filtering (2017–2021)
- 📊 Monthly Revenue Trend with Growth %
